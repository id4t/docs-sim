# Kontrak Resmi Menggantikan Perilaku Lama

Dokumentasi SIMGOS2 dan kode SIMPel digunakan sebagai baseline workflow dan mental model pengguna, tetapi regulasi, terminologi, playbook, serta kontrak API resmi terkini selalu lebih berwenang. Keputusan ini mempertahankan pengetahuan operasional legacy tanpa membekukan perilaku BPJS/SATUSEHAT yang mungkin sudah berubah.
