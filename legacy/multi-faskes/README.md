# Arsip Eksplorasi Multi-Faskes

Dokumen di direktori ini bersifat historis dan bukan spesifikasi target. Isinya merekam eksplorasi satu runtime untuk banyak faskes, database switching, provisioning, membership lintas faskes, serta credential per faskes.

Keputusan aktif sejak 31 Agustus 2026 adalah satu deployment untuk satu faskes. Gunakan [`../../BLUEPRINT-SIMGOS.md`](../../BLUEPRINT-SIMGOS.md), [`../../ARSITEKTUR.md`](../../ARSITEKTUR.md), dan ADR aktif sebagai patokan.

Arsip tidak dihapus agar alasan perubahan arah tetap dapat ditelusuri.
